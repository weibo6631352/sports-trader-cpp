## §1 老板 verbatim 约束

> "直到我们前后端能真正上线盈利"

**CPO 解析（三个关键词）：**

- **"真正"** — paper mode 不算，实盘净 PnL > 0 才算
- **"上线"** — 系统稳定在线，非一次性成交；须 ≥ 14 日连续运行
- **"盈利"** — 净 PnL > 0（扣除 gas + fee + slippage + spread cost）；统计显著，非噪声

**本 spec 任务：** 把"上线盈利"翻译成可量化、可 gate、可联决的 KR 数字。

## §2 北极星与 KR 关系

**北极星（T+36 月）：**
- 单策略年化 PnL ≥ $5M
- Sharpe ≥ 1.5
- 最大回撤 ≤ 15%
- 全盘口覆盖
- 系统在线率 ≥ 99.9%

**阶段化逻辑：**

北极星是 T+36 月终态。"上线盈利"是 T+24～36 周的阶段门禁，不是终态。
阶段 KR 必须满足三个条件才有意义：

1. **可测量** — 有具体数字 + 时间窗口 + 统计检验方法
2. **可达到** — 与当前 alpha 估算一致，不是拍脑袋
3. **可守门** — 未达标不能放行下一阶段

北极星分解路径：

```
北极星 $5M/年 Sharpe 1.5
    ↑
G5 Q1 单月净 PnL ≥ $10K, Sharpe ≥ 1.0 (T+36 月方向，阶段化降目标)
    ↑
G4 M5 首笔实盘成交验证（T+24 周）
    ↑
G3 Paper 2 周稳盈（T+22 周，M4.5 gate）
    ↑
当前：策略研究 + 回测 + alpha 估算
```

## §4 数字依据（老彭 + 小程 alpha v2）

**数字来源：老彭 OQ-P02-3 inplay alpha v2 估算**

| Alpha 来源 | Hit Rate | Edge | 备注 |
|---|---|---|---|
| Inplay alpha v2 | 54-58% | 1.5-2.5% per trade | 老彭估算，decay tau 25s |
| Pregame alpha | 56-60% | 2-3% | 8 家 de-vig 聚合 |

**G3 hit rate ≥ 54% 推导：**
- 来自 inplay alpha v2 下界 54%（保守取下界）
- 54% 在 50 trades 样本下统计功效约 40%（p 0.10 单尾）
- 功效不足警告：小董已在 M4.5 分析中标注，须累计窗口 + 末窗双判定

**G3 OOS Sharpe ≥ 0.5 推导：**
- Pregame 2-3% edge，假设日均 3 trades，年化约 $200K-$300K（$10K 本金）
- Sharpe 0.5 是"策略有效但尚未成熟"的保守门槛
- 小梁需确认此数字是否与其量化框架一致（见 §6）

**G5 月净 PnL ≥ $10K 推导：**
- 北极星 $5M/年 = 月均 $417K
- 起步阶段本金受限，OQ-D12 W3+ 单笔 $2K / 日累计 $20K / 总 $100K
- $100K 本金，月净 PnL ≥ $10K = 月收益率 10%，年化约 120%
- 这个数字偏高，**但对应北极星轨道**；若本金不足须同步提本金规划
- 老韩需确认 RM 框架下 10% 月收益率是否在风险承受范围（见 §6）

**关键不确定性（老彭 W8 W4 警报）：**
- Inplay fee/edge 比值 = 1.2-2x，净 edge 中位可能为负
- Polymarket 体育市场流动性薄，大 trade 滑点不可忽略
- **CPO 建议：G3 主跑 pregame，inplay 作为 stretch goal**
  - Pregame edge 2-3% > fee 门槛可能性更高
  - Inplay 若净 edge 为负，G3 跑 inplay 会导致 M4.5 持续失败
  - 等 G4 实盘验证后再决定 inplay 权重
