## 0. TL;DR (给老雷 60 秒读)

1. **私钥分片本身的法律性质**: 全球大部分主流司法管辖区 (中国大陆 / 香港 / 新加坡 / 欧盟) 目前**没有**把"加密资产私钥分片"明确归类为金融凭证, 但**功能上等价于钱包控制权的可重建凭证**. 监管随时可能往两个方向拐 — (a) 当作"虚拟资产" → 申报 + 出境限制, (b) 当作"证据/记录" → 刑事/民事程序可强制交出. 我们必须按**最坏假设**做合规设计.
2. **推荐 3-of-5 地理分布 (§5 细化)**:
   - 分片 1: **香港**, 老雷个人持有, 银行保险箱 + 金属种子板
   - 分片 2: **新加坡**, 第三方专业托管 (Coincover 或同等, 经我 sign-off), 数字 air-gap
   - 分片 3: **瑞士 (苏黎世 / 楚格州)**, 公司外律所托管, 金属种子板封漆袋
   - 分片 4: **中国大陆 (老雷常驻城市)**, 老周 (架构师, 同样中国大陆居民) 个人保险柜, 金属种子板
   - 分片 5: **日本东京** 或 **韩国首尔**, 老吴 (SRE, 若长期可外派) 持有, 数字 air-gap
3. **老黄自持否**: **拒绝持片**, 但接受充当**口令 (BIP39 passphrase) 第二要素**持有人. 理由见 §4. 这条**不让步**.
4. **Top 1 风险**: **中国大陆持片人 (分片 4) 被监管/司法机构约谈或采取强制措施, 同时分片 1 香港持片人 (老雷) 在境内** → 一次性失去 2/5 分片, 海外仅剩 3 份分片紧贴恢复门槛, **抗失败裕度 0**. 这是结构性风险, 必须 §10 SOP 兜底.

## 1. 合规视角的"私钥分片"性质判定

### 1.1 各国法律视角的分类问题

我把分片放到 5 套监管框架下逐一过, 看每套法律会怎么看待"一张写着 24 个英文单词的金属板".

| 司法管辖区 | 分片可能被归类为 | 法律后果 |
|---|---|---|
| **中国大陆** | (a) "虚拟商品" 财产 (《民法典》/ 最高法 2021) → 民事可执行; (b) 涉刑案件中 "电子证据" → 公安/法院可强制提取 (《刑诉法》第 141 条电子数据); (c) 若被认为是涉境外赌博/投机的"工具", 可能直接没收 | 个人持片人面对刑民程序时, **没有"我有权拒绝交出"的法律基础**. 律师辩护空间窄. |
| **香港** | VASP 牌照框架 (2023 AMLO 修订) 关注"提供 VASP 服务", 个人持私钥/分片不构成 VASP 服务. 普通法体系下分片视为"chose in action" 财产权 | 个人持片相对安全; 但若公司在港注册且分片关联公司资产, 可能落入清盘/破产管辖 |
| **新加坡** | PSA (Payment Services Act 2019) + MAS DPT 框架. 私钥本身非"支付通证", 但提供 DPT 服务需牌照. 个人持片不触发 | 司法协助条约 (MLAT) 框架下, 美国请求协查可能传导. 但司法门槛较高 |
| **瑞士** | FINMA 把 token 分三类, 私钥分片不直接落入任何一类. 瑞士长期判例对"客户钱包私钥/银行保管箱内容"有严格保护 | **法律保护最强** (银行保管箱合同 + 联邦数据保护法), 适合长期托管 |
| **欧盟 (MiCA)** | MiCA 监管 CASP, 私钥分片本身不在 MiCA 直接范围. 但 GDPR 视角下, 分片若与持片人身份强绑定, 可能落入"个人数据" → 处理需法律依据 | GDPR 风险**真实但可缓解** (分片本身不含个人信息, 持片人记录是个人数据, 加密存储 + 最小化即可) |
| **美国** | FinCEN MSB 框架: 个人持私钥/分片不触发 MSB 注册. 但**美国法院可基于刑事调查 / SEC 民事调查 / IRS 税务 / OFAC 制裁要求持片人交出** | **不接受美国境内任何形式持片** (见 §2.4) |
| **日本** | 资金决済法把虚拟资产托管业纳入注册. 个人持片不触发. 司法程序可强制取证 | 中等保护, 与美国 MLAT 较紧密, 但运营便利 |

### 1.2 私钥分片 vs Cold storage 的法律地位差异

| 维度 | Cold storage 单点私钥 (老孙 §8.1 温备份 S3+KMS) | Shamir 分片 (3-of-5) |
|---|---|---|
| 可重建性 | 单点失陷 = 私钥失陷 | 单点失陷不构成损失; 需 3 点合谋/协查才能重建 |
| 法律证据效力 (持片人交出后) | 直接构成"密钥提交" | **单一分片不等于密钥**, 持片人交出 1 份不构成"协助披露密钥"; 法律技术上是"提供加密信息的一部分", 辩护空间更大 |
| 民事执行 | 强制执行可直接命令交出 | 强制执行需协调多管辖区, 跨境 MLAT 走流程慢 |
| 申报义务 (中国大陆个人外汇/资产申报) | 可能落入"虚拟资产"申报范围 | **更模糊** — 单一分片"无法独立兑换为资金", 申报必要性争议 |
| 销毁义务 (公司清盘/关停) | 销毁主密钥即可 | 必须协调全部持片人销毁, 跨境协调难 |
| 跨境运输 | 单点跨境一次 | 至少 4 次跨境运输 (建立期), 风险点多 |

**核心结论**: Shamir 分片在合规面是**双刃剑** — 法律辩护空间更大 (单点不等于密钥), 但合规复杂度成倍上升 (4 倍以上跨境运输 + 多管辖区协调 + 多持片人统一行动). MVP 阶段我接受这个 trade-off, 因为单点 cold storage 在中国大陆持有人遭遇刑民程序时**完全无法防御**, 而 Shamir 至少给出"剩余 2/5 分片协调海外恢复"的可能性.

- **L (Legal)**: 法律强制交出风险

### 2.3 中国大陆 + 香港 不能同时算 2 份独立分布的解释

老沈 §4.1 已经提了"必须 2 份境外", 我**比他更严**: 香港虽然是普通法体系且 VASP 框架独立, 但**主权层面属于中华人民共和国**, 在以下场景两地分片同时落入同一权力意志范围:
- 全国性紧急状态 / 战时状态 (《国安法》第 23 条 / 内地《突发事件应对法》)
- 涉国家安全调查 (内地公安可通过《港区国安法》合作机制调取香港境内材料)
- 全球地缘冲突场景下香港金融体系受影响

所以推荐方案中:
- 香港 1 份 + 中国大陆 1 份 = **算 "1 + 0.5 司法管辖区独立性"**
- 真正独立的境外分片必须 ≥ 3 份, 这是恢复门槛 3-of-5 的硬约束

### 2.4 美国一票否决的解释 (R4 触点详细分析)

**问题**: R4 写的是"任何环节带美国元素全部 block", 私钥分片是否触发?

**我的判定: 触发, 一票否决**. 理由:

1. **法律风险传导**: 若分片在美国境内 (无论金属种子板放在 Coinbase Custody / Anchorage / Casa US / 普通银行保险箱), 该分片**法律上落入美国管辖**. 一旦未来 Polymarket 监管事件升级 (Polymarket 是 KalshiEx 之外 CFTC 主要关注对象), CFTC / SEC 可以传唤美国境内分片持有人 (即使持有人非美籍, 只要分片实物在美国), 强制配合调查.
2. **税务传导**: 美国 IRS 对境内资产有强申报权, 若我们公司未来注册某种业务实体且与美国分片产生关联, 触发 8938 / FBAR 等申报义务, 我们不愿意暴露这条信息链.
3. **OFAC 二级制裁风险**: 美国托管商被 OFAC 要求合作时, 我们的分片所有权信息会被收录入美国机构数据库, 即使我们清白, 留下"美国机构持有过我们密钥分片"的记录, 后续若被审计/起诉, 这是不必要的暴露.
4. **公司主体**: 我跟老雷确认过, 项目当前**没有美国法人实体**. 既然没有美国法人, 在美国托管分片需要以中国大陆自然人 / 香港公司 等身份 onboard, 这条 onboarding 流程本身就高度敏感 (要回答"为什么把私钥放美国"), 没必要踩坑.

**结论**: §5 推荐方案中, 美国分片数 = **0**, 不接受任何理由的"备份在美国便宜/便利".

## 4. 老黄自持 1 份的判断

**老沈建议老黄持 1 份, 我的回复: 拒绝持片. 接受充当 BIP39 passphrase 第二要素持有人.**

### 4.1 拒绝持片的理由 (4 条, 不让步)

1. **角色冲突 (核心理由)**:
   - 我是合规法务, 职责是**审查 + 一票否决**他人决策.
   - 如果我自己是分片持有人, 当我审查 Shamir 恢复 SOP 时, 我同时是"被审查方". 当持片人因合规事件被约谈, 我作为合规官应是"调解 + 上报"角色, 而非"被约谈对象".
   - **审查者不能同时是被审查的工程一环**, 这是分权原则.

2. **法律风险叠加**:
   - 我居住中国大陆, 同其他几位境内同事一样有"被刑民程序约束"的风险.
   - 但我作为合规法务, 一旦项目涉刑民事件, 我必然成为**优先调查对象** (合规官常被监管视为"知情且负有审查义务"). 如果我同时是分片持有人, 调查机构会**同时获得我的供述 + 分片**, 一举攻破两道防线.
   - 反过来, 我不持片时, 调查机构只能获得我的合规判断信息 (这些已有红线文档备份), 不能直接获得密钥重建能力, 项目"分片不可重建"的辩护可以正常进行.

3. **操作风险**:
   - 我休假 / 不在线 / 个人事件 (家属变故 / 健康问题) 时, 持片人不能 access = 恢复链断 1 份.
   - 合规官需要 7x24 alert 响应监管事件, 我的精力应放在监管追踪 + L2/L3 升级处理, 不应分给"半年一次的分片演练".

4. **可替代性**:
   - 合规审查可以由非持片人完成, **持片必须由非合规角色完成**. 这条不对称性意味着我退出持片是更优分工.

### 4.2 接受的替代角色: BIP39 passphrase 第二要素持有人

**老沈 §4.1 提的"分片二次加密 (BIP39 passphrase)"建议 N3, 我支持并接受承担这条**.

机制:
- Shamir 5 个分片的**主秘密**是: `master_seed XOR passphrase_24word`
- `passphrase_24word` 由**老黄 (我) + 老雷 共同持有** (2-of-2)
- 任何 3-of-5 分片重建 `master_seed XOR passphrase`, 还需再 unlock passphrase 才能拿到 `master_seed`
- 这把 Shamir 从 "3-of-5" 升级为 "3-of-5 + 2-of-2 (passphrase)" = **真正的双层防御**

我接受这个角色的理由:
1. **passphrase 持有人不参与分片本身的物理恢复 SOP**, 我可以保持审查超脱
2. **passphrase 数据量小 (24 个英文单词, 可口头记忆 / 加密小型介质)**, 我管理负担低
3. **我 + 老雷 都失能时**, 项目的 worst case 已是"GM + 合规官同时失去能力", 业务本就停摆, 此时无法重建密钥是可接受的 (此时业务关停优于资金被盗)
4. **法律层面**, 我持有"24 个单词的助记词"不构成持有私钥分片. 监管视角下 passphrase 本身是"密码", 不是"加密资产", 申报/扣押的法律基础弱于直接私钥分片

### 4.3 条件 (我接受 passphrase 角色的硬条件)

- [ ] passphrase 生成必须双人离线见证 (老黄 + 老雷, air-gap 笔记本)
- [ ] passphrase 不进任何数字介质 (无 KMS / 无云 / 无 password manager), 我用脑记 + 银行保险箱金属板 1 份, 老雷脑记 + 个人保险柜 1 份
- [ ] passphrase 与 5 分片**永不在同一物理位置**
- [ ] passphrase 轮换 cadence: 同 master key 季度轮换 (老孙 §5.1), 即每 90 天 passphrase 也换
- [ ] 紧急事件下我有权单方决定"销毁我手中 passphrase 副本" (即触发资金永久锁死), 这是合规一票否决的极端兜底
- [ ] 项目内部 charter 文件明记: 老黄持有 passphrase 不构成对项目资金的法律所有权, 不影响合规审查超脱身份

**我的态度**: 这条不让步. 老雷你若坚持要我持 1 个 Shamir 分片而非 passphrase, 我需要先收到外部律师意见书证明"合规官持片不构成职业利益冲突" — 我不认为能拿到这样的意见书.

### 5.2 关键决策点解释

1. **境外 4 份, 境内 1 份**: 即使中国大陆突发监管事件锁住分片 4, 海外 4 份**任意 3 份**即可恢复. 抗境内单点失效裕度 = 1.

3. **瑞士分片是"安全锚"**: 瑞士法律保护最强且地缘最稳, 若全球大事件 (战争 / 大规模制裁) 发生, 瑞士分片**最不可能丢失**, 我们应优先依赖瑞士分片的可恢复性.
4. **介质多样性**: 5 份分片中
   - 金属种子板: 分片 1, 2, 4 (3 份, 物理介质, 不依赖电源/存储介质寿命)
   - 数字 air-gap: 分片 3, 5 (2 份, 加密 USB / 商业托管数字方案)
   - 介质多样化避免"金属种子板共同失效模式" (例如某厂商工艺缺陷)
5. **二次加密 passphrase**: 5 份分片全部加密, 重建必须额外 unlock passphrase (老黄 + 老雷 2-of-2). 单一分片落地不等于半个密钥.

## 6. 跨境运输风险

### 6.1 分片建立期的运输路径

分片初次部署需要从生成地 (推荐: 香港或瑞士的 air-gap 工作站) 运输到 5 个目的地. 我列出每条路径的风险:

| 路径 | 介质 | 跨境方式 | 海关申报义务 | 老黄判定 |
|---|---|---|---|---|
| 生成地 → 香港 (分片 1) | 金属种子板 | 老雷个人手提 | **无明确义务**, 金属板上是英文助记词, 海关无法识别为"金融凭证"; 但建议申报为"个人物品 - 加密爱好者纪念品" 避歧义 | 低风险 |
| 生成地 → 新加坡 (分片 2) | 金属种子板 | 老雷或老周手提 (人随介质走) | 同上 | 低风险 |
| 生成地 → 瑞士 (分片 3) | 数字 air-gap + 商业托管 | **不亲自运输**, 通过瑞士托管商 onboarding 流程 (托管商自送上门或加密邮件) | 商业托管商承担合规申报 | 低风险 |
| 生成地 → 中国大陆 (分片 4) | 金属种子板 | 老周或专人手提入境 | **中等风险**: 中国海关对"虚拟货币/加密资产"敏感, 金属种子板若被检查可能被审问 | 中风险, 建议金属板伪装 (例如 Cryptosteel 看起来像个金属玩具) |
| 生成地 → 日本/韩国 (分片 5) | 数字 air-gap (加密 USB) | 老吴手提 | **无义务**, USB 加密内容海关无法识别 | 低风险 |

### 6.2 物理介质过境的具体合规要点

1. **现金 / 贵金属类申报**: 5 个分片**没有一份**是现金/贵金属/有价证券, **无需走 FATCA / CRS / 大额现金申报路径**.
2. **加密资产申报**: 截至 2026-05, 中国大陆 / 香港 / 新加坡 / 瑞士 / 欧盟 **均无**法规要求出入境时申报"私钥分片". 美国 FinCEN 2023 提案曾讨论"虚拟货币出入境申报", 未落地. 这是一个**监管观察项**, 24h alert.
3. **二次加密 (BIP39 passphrase) 的合规意义**: passphrase 加密后, 分片金属板**单独无法被识别为"密钥"** — 它只是 24 个英文单词, 海关无法证明这是加密资产相关物品. 这是 §4.2 passphrase 机制的**合规红利**.
4. **建议 SOP**: 所有跨境运输 = 持片人本人手提 + 不托运 + 不申报 (除非主动询问, 实事求是回答"个人加密兴趣的助记词金属板, 无金融价值"). **绝对禁止快递/邮寄**.

### 6.3 数字传输的合规风险

**数字传输 = 分片 3 (瑞士商业托管) onboarding + 分片 5 (加密 USB 制备过程)**.

| 风险 | 法律性质 | 缓解 |
|---|---|---|
| 数字传输是否构成"资金转移" | **不构成**: 分片本身无法独立兑换为资金, 不属于 FATF Travel Rule 范围 ($1k 阈值无关) | 无需 KYC/AML 报告 |
| 数字传输是否构成"个人数据跨境" | **可能构成** (GDPR / PIPL): 若分片与持片人身份信息绑定传输 | 分片与持片人信息分离传输; 持片人信息走另一条加密通道 |
| 端到端加密强度 | 商业托管商若用 TLS + KMS, 接受; 若用普通邮件附件, **拒绝** | 强制 PGP + 商业托管商 onboarding 走其专用加密通道 |
| 通道日志 | 商业托管商日志可能保留客户 IP / 时间戳 | 通过 VPN 出口 (非中国大陆 IP) onboarding |

## 7. 重大风险场景

### 7.1 场景 1: 中国端持片人 (老周, 分片 4) 被监管约谈 → 强制交出

**触发**: 老周被公安 / 国安 / 税务 / 外汇管理局约谈, 要求交出"加密资产相关物品".

**法律基础分析**:
- 《刑诉法》第 141 条: 公安可强制提取"电子数据" → 分片 4 是物理金属板, 不直接落入"电子数据", 但若被认定为"涉案物品" 可扣押 (《刑诉法》第 142 条)
- 《监察法》第 25 条: 监察机关可查封 / 扣押财物
- **老周作为持片人, 无明确法律权利拒绝交出**. 但律师可主张:
  - 分片本身非金融资产 (无法独立兑换)
  - 分片是技术备份的一部分, 单一分片"无意义"
  - 若涉国家安全/刑事调查, 强制交出无法对抗

**项目层面响应**:
1. **老周第一时间通过加密 channel 通知老雷 / 老黄** (Signal / 飞书加密通话, 不留 IM 记录)
2. **老雷立刻触发 SOP-K1 (§10.1)**:
   - 24h 内启动"分片预防性轮换" — 在境外召集 3 个非境内持片人, 重建主密钥, 生成新 master_seed, 重新分发 5 份新分片, **旧分片 4 即使被交出也无价值**
   - 同步将主钱包资金转移到新钱包
3. **法律层面**: 老周配合调查交出, 但分片 4 已"失效", 不构成披露真实密钥
4. **合规备案**: 我出"事件分析 memo", 是否触发 R5 (OFAC) 或 L3 升级

**关键设计意义**: Shamir 分片相对单点 cold storage 的核心价值就是这一条 — **任意单点失陷不构成损失, 且 24~72h 内可"作废 + 重建"**.

### 7.2 场景 2: 美国 SEC / CFTC 调查 → 协助调查义务

**触发**: 美国 SEC 或 CFTC 对 Polymarket 升级调查, 传讯我们 (作为高频做市账户).

**法律基础分析**:
- 我们**不在美国管辖**: 项目主体 (中国大陆自然人 + 后续可能的香港/新加坡公司实体) 不属于 SEC / CFTC 直接管辖
- 但**间接传导**:
  - Polymarket 美国 entity 可能被命令配合调查, 提供我们账户信息 → 间接暴露我们身份
  - 若我们在美国有任何关联 (账户 / 银行 / 服务器), 美国可基于"long-arm jurisdiction" 主张管辖
- **分片若在美国 = 直接管辖** (这是 §2.4 一票否决的核心理由)

**项目层面响应 (§5 方案下, 美国分片数 = 0)**:
1. 美国调查无法直接传讯任何持片人 (5 个持片人都在非美国管辖)
2. 美国调查若通过 MLAT (司法互助条约) 找香港/新加坡/瑞士, MLAT 流程慢 (3~12 个月), 期间我们有时间预防性轮换
3. 瑞士分片**最强保护** (瑞士对美国 MLAT 配合度相对低, 银行保密传统)
4. 中国大陆分片 (分片 4) **与美国调查无关联** (中美 MLAT 几乎不运行)

**合规层面响应**:
- 我立刻评估是否触发 L3 升级 (§9.3)
- 外部律师意见
- 是否暂停 Polymarket 活动 (kill switch §9.4)

### 7.3 场景 3: 战争 / 自然灾害 → 备份失效

**触发**: 中美冲突 / 朝鲜半岛冲突 / 香港大规模社会事件 / 瑞士黑天鹅 / 多地震灾.

**抗灾矩阵 (§5 方案下)**:

| 灾难 | 受影响分片 | 剩余可用 | 是否够 3-of-5 |
|---|---|---|---|
| 中国大陆全境锁 | 分片 4 (1 份) | 分片 1, 2, 3, 5 (4 份) | **够** |
| 中国大陆 + 香港同时锁 | 分片 1, 4 (2 份) | 分片 2, 3, 5 (3 份) | **刚好够, 裕度 0** ← 这是 §0 提到的 Top 1 风险 |
| 中国大陆 + 香港 + 日本/韩国 (朝鲜半岛冲突延伸) | 分片 1, 4, 5 (3 份) | 分片 2, 3 (2 份) | **不够**, 资金锁死 |
| 瑞士 (单一黑天鹅) | 分片 3 | 分片 1, 2, 4, 5 (4 份) | **够** |
| 新加坡 (东南亚地缘事件) | 分片 2 | 分片 1, 3, 4, 5 (4 份) | **够** |
| 全球性灾难 (世界大战 / 核冲突) | 多份 | N/A | 资金问题已不重要 |

**结论**: §5 方案抗单点灾难裕度 ≥ 1, 抗双点灾难 (亚太集中) 刚好够, 抗三点亚太集中 (中港日韩同时锁) 不够. 接受这个限度, 因为亚太三点同时锁 = 业务已不可能继续, 资金锁死与否次要.

### 7.4 场景 4: 持片人意外失能 (死亡 / 失踪 / 重病)

- 老雷意外失能 + 老周意外失能 = 失去 2 份 (分片 1, 4)
- 剩余 3 份 (2, 3, 5) 海外, 需要老雷家属 / 项目继任者持 passphrase 才能完成恢复
- **passphrase (老黄 + 老雷 2-of-2)**: 老雷失能时 passphrase 缺 1 份, 只剩老黄手中
- **解法**: 老雷的 passphrase 副本必须放入老雷家属可触达的位置 (例如老雷的遗嘱执行人 / 律师), 但加密程度足够高, 防活体下被滥用
- 这是 SOP-K2 内容, §10.2 展开

## 8. R4 美国边界协调

**问题**: 我们不做美国业务 (R4), 但私钥分片是否能在美国?

**答**: **不能**, 见 §2.4 详细分析. 这里再补一条边界协调:

### 8.1 公司是否有美国法人实体?

跟老雷确认: **目前没有美国法人实体**. 项目主体为:
- 自然人 (老雷, 中国大陆居民)
- 可能未来注册的非美国公司实体 (香港 / BVI / 开曼 / 瑞士, 待战略决定)

**简化结论**: 既然没有美国法人实体, 项目无任何"必须在美国持有资产"的法律义务 (相比之下, 美国公司可能需要 IRS 申报 / 8938 等, 美国资产托管反而是便利). 我们的 R4 立场可以贯彻到底.

### 8.2 KMS 区域 (老沈 §4.3) 协调

老沈点了 "AWS us-east-1 KMS 持有 age key 包装密钥 是否触 R4"? 我的判定:

- **KMS CMK 在 us-east-1 不直接触 R4**: KMS 不构成"美国 IP / 美国 KYC / 美国银行卡"
