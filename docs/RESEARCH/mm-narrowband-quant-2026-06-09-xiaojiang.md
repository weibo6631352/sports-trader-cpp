## 0. 结论先行 (净正吗?值得做吗?)

**不值得做。把产能放回目标仓位控制框架。** 三条量化理由,逐条带数字在 Q1-Q4:

1. **窄区间 MM 的净正【数学上存在但实操上测不准】。** 在乐观假设下 (tennis 真紧簿、良性 fill 占比 φ=95%),净 carry ≈ **+0.875c/fill (+87 bps notional)**,看着很肥。但这个数完全由一个**我们测不准的参数 φ (良性 fill 占比)** 决定:break-even φ = adverse/(carry+adverse)。温和移动下 break-even φ=60% (容错宽),**但极价区崩盘 adverse=31.5c 时 break-even φ 跳到 95.5% — 知情 fill 只要超 4.5% 就净负**。而我们**没有逐笔成交 tape**(老韩 §9 #1),φ 在生产里测不出来。逆向选择的定义就是「informed taker 优先挑要移动的盘吃」→ maker fill 的 φ 内生偏低,我们押的是一个看不见的硬币正反面。

2. **「退场而非撤单」结构上比撤单可行,但挡不掉第一口,且 size 极小时边际价值趋零。** 老韩 §4.4 铁证:92% 的大幅逆选移动**无前兆**,第一口 fill 撤单/退场都救不了。退场的**唯一**真实价值是「被扫后不补单、阻断连续被扫」——但当 size 已被 RR-MM 压到极小 (~$100/fill),单口损失就是主要项,退场挡的「tick2..N 连续暴露」边际价值随 size 缩而递减。即:**为了让尾部可控必须把 size 压到极小 → 极小 size 下退场又没多大用 → 整个安全机制自我消解**。

3. **窄区间 MM 与现有「单边跟随 sharp」框架【直接冲突,非互补】。** 双边 MM 的 **sell 腿 = 在 sharp 看好的边上主动卖 = 抢跑 sharp 反向**,这恰恰是 `position_controller.hpp:188` 已审定 A-S 卖侧 skew SKIP 的同一条违规理由(违 2026-06-05「方向真值=赔率源 sharp」裁决)。现框架的被动 reservation 限价**已经吃到了 MM 能合法吃到的那部分 carry**(maker 0 费 + 半 spread 留存),双边 MM 多出来的只有「非法的 sell 腿」。**窄区间 MM 不是现框架缺的一块,是现框架已经合法覆盖 + 砍掉违规腿后剩下的空集。**

**经济量级佐证不值得:** 即使按最乐观 500 fills/日 × φ=95% 算,MM 年化贡献 ≈ **$109k/年 = 北极星 ($5M) 的 2.2%**,却要新增双边报价引擎 + φ 测量管线 (逐笔 tape) + 退场状态机 + RR-MM-1~8 八条红线的工程与风控复杂度。**复杂度/回报比极差,且回报建立在一个测不准的 φ 上。** 同样产能投到目标仓位控制 (相关性折扣、CLV、生命周期乘子已落地待 paper 验证) 的边际回报远高、且不依赖测不准参数。

## Q1. 窄区间的边界在哪 (安全窗 / 簿宽门 / size 上界)

### Q1.1 价格安全窗 — 反直觉:near 区比 mid 核心区尾部更肥

老韩 §4.1 realized move p99 (挂 mid 的 resting 单,未来一 tick |Δmid|,per $100 notional):

| 价位区 | p99 (c) | 紧簿占比 | top3 深度 median | 崩盘尾部 |
|---|---|---|---|---|
| extreme_lo <0.15 | 2.0 | 69% | 1394-1861 | 领先方崩盘 |
| **mid 0.35-0.65** | **1.5 (最低)** | 31% (45% 幻影簿) | 458 (最薄) | 无对称崩盘统计 |
| near 0.15-0.85 | **4.0 (最高!)** | 68% | 2196 (最厚) | — |
| extreme_hi >0.85 | 2.0 | 69% | 1394-1861 | **p99=31.5 / p999=49.5 / max=53.5** |

**安全窗判定 (两个约束打架,取交集):**
- **崩盘约束** → 排除极价区 mid>0.90 / mid<0.10:gap-through (买 0.90 跌 0.40 亏 50c) 集中在这里,markout p99=121c >本金。
- **幻影簿约束** → 排除 mid 0.35-0.65 的**幻影簿子集**(45%,bid≈0.04/ask≈0.96 把 mid 数学推到 0.5):贴 mid 挂 = 送免费期权 (老韩 §2)。
- **尾部约束** → near 区 (0.15-0.85 非中) p99=4.0c 居然**最肥**,反直觉。但深度也最厚 (2196)、紧簿占比最高 (68%)。

**结论:真正的安全窗 = `mid ∈ [0.35, 0.65] 的真紧簿子集`(占该区 51%,p99 仅 1.5c 最低),叠加 `book_depth ≥ 500 USDC + spread ≤ 6c` 物理过滤掉幻影簿。** 而非老韩裁决直觉里的「极价甜区」——极价区 carry 最肥 (1.5c) 但崩盘尾部最毒 (p999=49.5c),容错为零 (见 Q3)。near 区被排除是因 p99 尾部反而最肥。**这个安全窗很窄,且需要逐 tick 区分真紧簿 vs 幻影簿,本身就是一个非平凡的实时判据。**

### Q1.2 簿宽门

`spread ≤ 6c`(老韩 §3 真紧簿定义,best_ask − best_bid ≤ 0.06)。spread > 8c → 禁 (RR-MM-6)。理由:spread 宽 = 薄簿 / 知情者拉宽 / 幻影簿,这些都是逆选信号。深度门 `top3 ≥ 500 USDC` 配套(幻影簿 mid 区深度只有 458)。

### Q1.3 size 上界 — 由最坏 gap-through 反推

最坏单次损失 = markout p99 = **121c per $100 notional**(gap-through,极价区)。若约束「单次最坏损失 ≤ 日 carry 的某倍」:

- 设单边挂单 notional = S,最坏单次损失 = S × 1.21(p99 markout)。
- 日 carry (乐观) = fills/日 × S × 0.875%(净,Q3)。设 200 fills/日 → 日 carry = 1.75 × S。
- 要求 最坏单损 ≤ 1× 日 carry:S × 1.21 ≤ 1.75 × S → **恒成立?** 否——因为 gap-through 损失是 1.21×S 在**单一 fill 的 S** 上,而日 carry 是 200 个 fill 累积。正确约束:**单 condition 库存 VaR ≤ 0.3% bankroll**(RR-MM-1),极价区 ≤ 0.05% bankroll(RR-MM-2b)。bankroll $50k → 非极价单边库存 ≤ $150,极价区 ≤ $25。
- **这就是命门 Q3 会展开的:为了兜住 121c 的 gap-through 尾部,size 必须压到 $25-150 级,而这个 size 下 carry 的绝对额 (¢级 × $100) 小到工程复杂度根本不值。**

## Q2. 退场而非撤单,结构上够吗

### Q2.1 撤单为何失效 (老韩 §4.4 复述,load-bearing)

8,777 次大幅 realized 移动 (>5c) 中,只有 **8.0%** 在前一 tick 有 sharp 预警,**92% 是无前兆突袭**。撤单触发器在模拟里只触发 0.5% 的 rest,对 PnL 改善 <0.4%。**撤单网络速度 14ms 毫无意义** —— 命门是「看见」(检测延迟),不是「撤」(网络速度)。

时间预算:

| 环节 | 延迟 | 性质 |
|---|---|---|
| 撤单网络往返 (warm) | 14ms | 不是瓶颈 |
| book 新鲜度 | 1.9-5s | **检测延迟** |
| sharp (GS) 落后真实赔率源 | P50 2.3s (memory: gs-bet365) | **检测延迟** |
| 同 condition tick 间隔 | median 5.09s | 移动在单 tick 内已发生 |

检测延迟 (5s) 比撤单速度 (14ms) 大 **357×**。

### Q2.2 退场能挡多少尾部 — 三段量化

1. **第一口 fill:挡不掉。** 92% 突袭无前兆 → 已挂单在突袭那一 tick 就被扫穿,退场和撤单一样来不及。**这部分尾部 (单口 markout,median 4c / p99 121c) 是结构性不可避免的成本,任何「退场」机制都吃不掉。**

2. **退场的唯一真实价值 = 阻断「连续被扫」。** 完整崩盘 (0.85→0.55 在 60s 内,老韩 §6,占 0.3% condition) 持续多 tick。退场 = 被扫后**不再补单 + 主动 taker 平库存**,阻止 tick2..N 的继续暴露。**这部分能挡。**

3. **但 size 极小时,退场边际价值趋零。** RR-MM 把 size 压到极小 ($25-150) 是为了兜尾部 → 单口损失已是主要项,「tick2..N 连续暴露」相对单口已经不大 → 退场挡的那块随 size 缩而递减。**自我消解悖论:size 压小到能兜尾部 → 退场没多大用;退场要有用 → size 得大 → 尾部又兜不住。**

### Q2.3 退场 vs 撤单的结构差异 (退场为何仍略胜)

- **撤单**:要抢在移动**前**撤掉已挂单 → 本质是**预测**移动来临 → 92% 看不见 → 失效。
- **退场**:被扫**后**「认怂、不再挂新单」→ 本质是**确认已发生的 regime 变化**(波动起 / 簿变薄 / 临近事件)。regime 是**持续状态**非**瞬时跳变** → 检测延迟 (5s) 可容忍(状态持续几个 tick,5s 后看见仍有效)。

**结论:退场结构上确实比撤单可行(不依赖预测,只依赖确认)。老韩 RR-MM-3「持仓超 T 秒强制 taker 退场」方向对。但 (a) 挡不掉第一口、(b) size 极小时边际价值趋零 —— 退场是「比撤单不那么虚」,不是「让窄区间 MM 安全」。** 且退场自身有 book_fresh=5s 的延迟:簿在 t 变薄,我们 t+5s 才看见,这 5s 内的 fill 退场也来不及——退场不是免检测延迟,只是对检测延迟不那么敏感。

## Q3. carry vs 逆选 净值 (核心经济,命门在 φ)

### Q3.1 carry 侧 (确定的、为正的)

maker 限价单 **0 费**(`posmgmt-predmarket-fee-v1.md`:taker 才付 `rate·p(1−p)`,maker 成交费表全归零)。半 spread carry (老韩 §3):

| 价位区 | carry (c/fill) |
|---|---|
| extreme | 1.50 (最高) |
| near / mid 真紧簿 | 1.00 |

tennis 非极价真紧簿:**carry = 1.0c/fill = 1.0% notional/fill**。这一侧扎实。

### Q3.2 逆选侧 — 正确的条件建模 (不是随机 tick 的 move_mean)

**两个偏置必须同时避开:**
- **悲观偏置 (老韩 §5):** 模拟 markout 只选中「价格已穿过我们」的 fill → 结构性全逆选 → PnL 全负是**下界**,不是无偏估计。
- **乐观偏置 (本文必须避免):** 若用随机 tick 的 `move_mean`(tennis 0.053c)算逆选,等于假设 fill 时点随机 → 严重**低估**逆选,会算出 +0.95c/fill 的假净正。

**真相:fill 是条件事件。** 净值 = `φ·carry − (1−φ)·E[adverse | informed]`,其中 φ = 良性 (uninformed) fill 占比。

**break-even φ = adverse / (carry + adverse):**

| 场景 | carry | adverse | **break-even φ** | 容错 (知情 fill 上限) |
|---|---|---|---|---|
| 温和移动 (tennis 非极价) | 1.0c | 1.5c (§4.3 sharp 跳>2c 时 \|Δmid\| p90) | **0.600** | 知情 < 40% 才净正 |
| **极价区崩盘** | 1.5c | **31.5c** (§4.3 高价单 tick p99) | **0.9545** | **知情 < 4.5% 才净正** |

净值随 φ (温和移动场景):

| φ (良性) | 净/fill (c) | 判定 |
|---|---|---|
| 0.95 | +0.875 | 净正 |
| 0.90 | +0.750 | 净正 |
| 0.80 | +0.500 | 净正 |
| 0.60 | 0 | break-even |
| <0.60 | 负 | **净负** |

### Q3.3 命门:φ 在生产里测不准,且内生偏低

1. **测不准:** 区分良性 vs 知情 fill 需要**逐笔成交 tape**(taker 主动方 / size),老韩 §9 #1 明确「当前没有」。5s tick + mid 穿越代理区分不了。**φ 是这个子策略净正与否的唯一开关,而我们读不到这个开关的状态。**
2. **内生偏低:** 逆向选择的定义就是「informed taker 优先挑要移动的盘吃我的挂单」→ maker fill 的 φ 系统性低于「随机 fill 假设」。乐观说 φ=0.95,但真实 φ 可能是 0.7、0.5,我们**无法证伪**。
3. **极价区容错≈0:** break-even φ=95.5% 意味着知情 fill 只要超 4.5% 就净负。极价区 carry 最肥 (1.5c) 的诱惑下,容错却最小 —— 这是「捡硬币 vs 压路机」(老韩 §6:~每 300 场一次崩盘吃掉 ~3000 场的 carry)的精确数学表达。

### Q3.4 年化贡献 (即使按最乐观假设)

假设 tennis 非极价、φ=0.95(乐观)、净 0.875c/fill、单 fill notional $100、bankroll $50k (MM 份额 20% = $10k):

| fills/日 | 日 PnL | 年 PnL (250 日) | 占北极星 ($5M) |
|---|---|---|---|
| 50 | $43.75 | $10,937 | 0.22% |
| 200 | $175 | $43,750 | 0.88% |
| 500 | $437.50 | **$109,375** | **2.19%** |

**即使最乐观 500 fills/日,MM 贡献仅北极星的 2.2%**,且这 2.2% 完全建立在 φ=0.95 这个测不准 + 内生偏低的假设上。真实 φ=0.7 时,温和场景仍净正但只剩 +0.55c/fill,极价区直接净负。**这个回报不值得新增「双边报价引擎 + φ 测量管线 (逐笔 tape) + 退场状态机 + 8 条 RR-MM 红线」的复杂度。**

## Q4. 与现有目标仓位控制框架的关系 — (a) 冲突

**确定判断:窄区间 MM 与「单边跟随 sharp 的目标仓位控制」是 (a) 冲突,且现框架已合法覆盖 MM 能合法吃到的全部 carry。**

### Q4.1 现框架已具备的 MM 要素 (`position_controller.hpp` 实测)

| MM 要素 | 现框架已有 | 出处 |
|---|---|---|
| maker 限价不追 (0 费 + 半 spread) | ✓ | `ComputeReservation` (fair ± fee ± margin) |
| 死区防费磨损 (p(1−p) 缩放) | ✓ | `ComputeRebalanceDeadband` |
| 逆选/毒性软档 (压价) | ✓ | `exec_margin = k_tox·\|OFI\|/depth + k_vol·σ²·τ` |
| 逆选/毒性硬档 (冻结加仓) | ✓ | `ToxicityFreezesAdds` (\|OFI\|/BidAbsence 超阈) |
| 库存 skew (q→更挑剔) | ✓ | `gap = target − current` 本身就是 A-S 库存机制 |
| **双边同时报价** | ✗ | 控制器是**单边** (gap 符号定方向,不同时挂 buy+sell) |

### Q4.2 唯一的差 = 双边 MM 的 sell 腿,而它是非法的

双边 MM = 同一 token **同时**挂 `buy@bid` + `sell@ask` 赚 spread。现框架单边:`target>current` 挂 buy / `target<current` 挂 sell,**不同时**。

**冲突的精确表述:** 若 sharp 说该 long 这个 token,你的 MM `sell@ask` 腿就是在**卖掉 sharp 说该持的仓 = 对抗自己的 alpha = 抢跑 sharp 反向**。这与 `position_controller.hpp:188` 已审定 A-S 卖侧 skew SKIP 的**同一条违规理由**:

> 「卖侧 A-S skew (库存大就主动压价卖) = 抢跑 sharp 反向,违 2026-06-05 裁决」

双边 MM 的 sell 腿 = 在 sharp 看好的边上主动卖 = 同样违规。

### Q4.3 结论:窄区间 MM = 现框架合法覆盖 + 砍掉违规腿后的空集

- 现框架的被动 reservation 限价**已经吃到了** maker 能合法吃到的 carry:0 费 + 半 spread 留存(买在 `fair − fee − margin` 比 ask 低,卖在 `fair + fee + margin` 比 bid 高,这就是赚 spread)。
- 双边 MM 比现框架**多出来的唯一东西** = sell 腿,而 sell 腿在 sharp 看好边上 = 抢跑 sharp 反向 = 已被裁决砍掉。
- **所以窄区间 MM 不是现框架缺的一块拼图,是「现框架已合法覆盖的 carry + 一条已被砍掉的违规腿」。把它当独立子策略立项 = 重新引入已经裁决禁止的卖侧抢跑。**

**唯一理论上的非冲突场景 = 不同盘口分工**(MM 只做 sharp **无覆盖**的盘口,与目标仓位控制物理隔离)。但 sharp 只覆盖 11% 的 tick(老韩 §1),无 sharp 的 89% 盘口里我们**既没有方向真值、也没有逆选预警** → 这恰恰是 RR-MM-5b 明令 fail-closed 禁做的区(sharp 覆盖 <80% 不开)。**「互补」的那个空间正好是红线禁区。** → 仍是 (a) 冲突,不是 (b) 互补,也不是 (c) 被覆盖之外还有剩余价值。

## 5. 给 GM 的一句话

**窄区间 MM 不值得做。** 净正在数学上存在,但 (1) 它由一个**生产里测不准、且内生偏低的参数 φ**(良性 fill 占比)单点决定,极价区容错只有 4.5%;(2)「退场」比撤单略可行但挡不掉第一口、且 size 压到能兜尾部时退场又没用(自我消解);(3) 它与现框架**冲突**——多出来的 sell 腿正是已被 2026-06-05 裁决砍掉的「抢跑 sharp 反向」,而现框架的被动 reservation 限价**已经合法吃到了 MM 能吃的全部 carry**。最乐观估算年化也只贡献北极星的 2.2%,却要背双边引擎 + 逐笔 tape 管线 + 退场状态机 + 8 条红线的复杂度。**产能放回目标仓位控制**(相关性折扣 / CLV / 生命周期乘子 / 毒性 margin 已落地待 paper 验证),那里的边际回报更高,且不押在一个看不见的硬币上。

> **诚实边界:** 若未来补齐逐笔成交 tape(能直接观测 φ)+ sharp 覆盖提到 80%(RR-MM-5b 达标),「窄区间 MM 净正可测」这个前提会成立 —— 那时可在 paper 实测 φ 后重启评估。但**在当前数据管线下,这是一个无法验证净正、且与现框架违规重叠的子策略,不立项。** 这与老韩 2026-06-03 裁决一致(有条件可做 / 当前不满足前置条件),本文补的是「即使满足前置条件,回报量级 vs 复杂度也不划算 + 与现框架是冲突非互补」的微观结构判断。
