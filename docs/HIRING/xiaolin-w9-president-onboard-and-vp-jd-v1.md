### 2.4 互相监督机制 Spec

老板 verbatim "互相监督" 落地规则:

| 决议类型 | 触发条件 | 双 ack 要求 |
|---|---|---|
| ADR 立项 | 任何新 ADR 编号发布 | 总裁 (P-00) + 副总裁 (P-01) 均须 ack |
| 预算审批 | 单次或月度增量 > $500 | 双 ack, 任一可发起, 需对方确认 |
| 班底变更 | 新增 / 离职 / 转岗任何 persona | 总裁 + HR (小林) 联决, 副总裁 review |
| 红线事故 P0 | 任何红线触发 | 总裁主导 post-mortem, 副总裁独立核查报告 |
| 异议升级 | 双方对重大决议有分歧 | 升老板 (退出期通过周报/紧急通道) |
| 日常运营 | Sprint 排期 / wave 派单 | 总裁单独 ack, 副总裁 review 周报即可 |

**关键约束:** 副总裁对总裁重大决议有 review 权, 但非 veto 权 — 分歧时升老板, 老板 final say. 这与老郭的架构 veto 权 (技术层) 不冲突.

### 3.2 角色定位

副总裁是总裁的协作伙伴与监督方. 老板 verbatim 明确"与你协助, 也算是互相监督" — 这意味着 VP 不是秘书, 不是执行层, 而是具备独立判断力、能对总裁决议提出实质性 review 意见的高级管理职位.

### 3.3 候选人 Profile (Who You Are)

**你是:**
- 在高科技 / 量化交易 / fintech / 创业公司有 8+ 年管理经验的高级管理者
- 习惯在高速迭代环境中跨部门推动执行, 不依赖完整文档也能快速上手
- 有能力独立阅读 ADR / 架构文档并提出实质性意见, 不懂技术细节但懂"为什么这个决策合理"
- 对量化交易 / Polymarket / DeFi 有基础认知 (不要求专家), 愿意快速学习
- 性格上: 直接 / 数字说话 / 不耻下问 / 敢于对总裁说"我不同意"

**你不是:**
- 总裁的执行助理 — 副总裁有独立 review 权
- 技术架构专家 — 技术判断依赖老郭等顾问团
- 运营 PM — 日常 Sprint 排期仍由老胡主持

### 3.4 职责范围 (Responsibilities)

**核心职责 1: 互相监督 (老板 verbatim 首要任务)**
- 对总裁发起的重大决议 (ADR / 预算 > $500 / 班底变更 / 红线 P0) 独立 review
- 有异议时必须书面记录 (不可沉默放行), 分歧升老板
- 每周向老板提交独立简报 (1 页, 独立于总裁周报), 内容包括: 重大决议 review 结论 + 任何需老板关注的风险

**核心职责 2: 总裁日常协助**
- 跨部门资源协调 (5 主管之间冲突时, 协助总裁裁决前先做事实收集)
- 顾问团联络 (与老郭协调架构评审日程 + 顾问团 backlog 优先级)
- Stage-Gate 联合主持 (与老胡 PM 联合主持月度 Stage-Gate, 确保 milestone 达标)
- 会议纪要质量把关 (确保重大决议有 audit trail)

**核心职责 3: 老板退出期间风险雷达**
- 每两周向老板发送"风险雷达"简报 (格式: Top 3 risks + 建议 + 需老板拍板事项)
- 识别总裁决策盲区 (单点、路径依赖、跨单元冲突被低估等)

### 3.5 任职资格 (Requirements)

**必须具备:**
- 8+ 年高科技 / 量化 fintech / 创业公司高管经验 (VP / Director / COO 层级)
- 有跨部门协调成功案例 (能说清楚: 谁 / 什么冲突 / 如何解决 / 结果)
- 具备"数字说话"习惯 — 提任何观点带量化依据
- 英文 working proficiency (Polymarket 协议文档 / vendor 沟通)
- 公司四条价值观高度认同: 实盘优先 / 纪律高于收益 / 数字说话 / 不耻下问

**加分项:**
- 有 Polymarket / 预测市场 / DeFi 实际操作经验
- 有量化交易公司管理经验 (含风控理解)
- 熟悉 C++ 工程文化 (不需要写代码, 但理解"热路径 / 延迟敏感"意味着什么)
- 有 AI agent / multi-agent 系统协作经验

**红线 (不录用):**
- 有风控意识缺失历史 (曾主导忽视风险的重大决策且无复盘)
- 无法接受"互相监督"定位 (需要确认 VP 是对等监督者, 不是总裁助理)
- 价值观不符 (藏问题 / 数字造假 / 越界 / 越权)
